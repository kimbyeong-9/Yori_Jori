## 작업 B — Figma MCP로 포트폴리오 제작 (자동화)
아래 순서를 반드시 지키세요. 각 Figma 도구를 호출하기 전에 명시된 스킬을 먼저 로드하세요
(스킬을 건너뛰고 도구를 바로 호출하면 실패합니다).

1. `figma-create-new-file` 스킬 로드 → `create_new_file` 호출
   (editorType: design, fileName: "리쿡(ReCook) 서비스 포트폴리오")
2. `figma-use` 스킬 로드 → `use_figma` 호출을 반복하며 아래 섹션을 프레임 단위로 구성:
   - 표지 (서비스명 + 한 줄 소개)
   - 핵심 사용자 흐름 (재료 등록 → 냉장고 선택 → 추천 → 상세 → 저장/조리)
   - 현재 화면 요약 (6~7개 페이지, 각 역할을 텍스트로 정리 — 실제 스크린샷이 없으면
     와이어프레임 형태 박스로 대체)
   - Before/After 개선 방향 (작업 A 내용을 표/카드 형태로)
   - 기술 스택 구조 (프론트/백엔드/DB/AI 연동을 박스+화살표로 직접 배치. 별도 다이어그램이
     필요하면 `figma-generate-diagram` 스킬을 먼저 로드한 뒤 `generate_diagram` 사용)
3. 완성된 Figma 파일의 URL을 확보하세요.
